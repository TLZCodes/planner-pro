# Asset Registry

Two pipelines are registered here.

**The client walkthrough tour — the shipped deliverable.** Its assets are the 28 recorded
stops in `edit/tour/`. Every stop passed numeric QC, so all of them are `locked`.

**The educational showcase stills — built, not shipped.** Their assets are the 27 captured
screens in `selects/`. They are used as documentation and by the tour's stop design.

## Notes

- Status moved from `draft` to `locked` on the strength of a recorded pass, not a judgement:
  every tour stop has a measured QC result in `edit/qc/`, and every still has a non-trivial
  file size and a distinct frame.
- `@phone_frame` is no longer an invented bezel. Nothing is drawn around the app: the
  recording is scaled to the full frame height and its width is derived from the real 824×1830
  aspect, with the leftover side strip filled with the app's own canvas colour.
- Versioned names are never reused. A re-recorded stop that changes content gets a new segment
  file; `seg-NN.webm` is only overwritten while the stop is still unreleased.

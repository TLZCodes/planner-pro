2. Detailed Root Cause & Targeted Corrections

Finding 1: Weekly Reset Missing Habit Denominator

  • Root Cause: In ResetOverviewStep.tsx, the component attempted to read metrics.habitProgress.scheduledOccurrences, which was absent from the WeeklyHabitProgress return type of computeWeeklyProgress(). Consequently, habitDenominator evaluated to undefined, rendering 4 / and an incomplete supporting sentence.
  • Correction:
    1. Updated src/lib/weeklyHabitEngine.ts to export scheduledOccurrences in WeeklyHabitProgress (weekInfo.isCurrentWeek ? dueOccurrences : totalWholeWeekPossible).
    2. Updated ResetOverviewStep.tsx to read canonical metrics and format localized sentences:
      • English: {completed} completed of {denominator} scheduled through today
      • Arabic: {completed} من أصل {denominator} عادة مستحقة حتى اليوم
    3. Handled zero-habit cases with a neutral badge (No Habits / لا عادات) and 0 / 0.

Finding 2: Journal Tabs Excessive Multi-line Wrapping

  • Root Cause: Journal tabs used flex-1 across all buttons within a max-w-md container, squeezing 5 tabs into small viewports (≤390px) and forcing labels like "Week in Bloom 🌷" to wrap across several lines.
  • Correction:
    1. Replaced the flex container with a horizontally scrollable container (overflow-x-auto no-scrollbar scroll-smooth).
    2. Applied whitespace-nowrap shrink-0 to all 6 tabs, guaranteeing single-line readability.
    3. Added smooth auto-scrolling into view (activeTabRef.current?.scrollIntoView({ behavior: 'smooth', inline: 'center', block: 'nearest' })).
    4. Added edge gradient fade scroll cues and 40px accessible touch targets.
    5. Added aria-hidden="true" to Lucide SVG icons.

Finding 3: Vision Board Duplicate Empty State Actions

  • Root Cause: VisionBoardCollection.tsx rendered "Create my board" and "Preview layouts" buttons in the sticky header as well as in the empty state card below it.
  • Correction: Wrapped header buttons with {displayBoards.length > 0 && (...)}. When empty, only the card actions appear. Layout previews create 0 records until explicitly confirmed.

Finding 4: Guest Data Honest Zero-Fabrication

  • Root Cause: defaultState in store.tsx had hardcoded demo records (tasks, habits with streak 21, study minutes totaling 255, 30 XP). Fresh guest launches received fabricated history.
  • Correction: Initialized all defaultState arrays to [] and xp: 0. Updated loadInitialState to preserve existing user records while ensuring fresh profiles start completely clean.

Finding 5: Future Me Time Capsule Discoverability & Experience

  • Root Cause: The core logic existed in futureMeEngine.ts, but was absent from Journal templates, lacked a navigation tab, and had no view component.
  • Correction: Added future_me template card, added capsule tab to Journal, and built FutureMeCapsuleView.tsx with sealed envelope cards, live countdown chips, composer modal, leap-year safe date calculations, and maskSealedCapsuleForPublicView for privacy.
